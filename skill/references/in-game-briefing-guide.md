# 游戏内战情简报指南

本指南供 skill 在信息不足、首次同步、排障和跨设备 handoff 时，把工具状态翻译成玩家能在 Civ6 里完成的操作。

## 面板位置

- 入口在 Civ6 原生左上 LaunchBar，按钮提示为「打开战情简报。」；对玩家可称为“左上副官入口”。
- 打开后面板标题是「战情简报」。
- 面板状态区显示两行：当前状态，以及「最近汇总：…」。
- 玩家点击「更新战情」后，面板会显示战情或可见地图的更新进度；成功状态应显示「简报已汇总，可继续由AI副官分析。」；最近更新一栏显示最近更新的回合数。
- 不要求玩家读取 `exportId`、chunk、checksum、manifest 或 sha256；这些只给日志、doctor、preflight 和 bridge 使用。

## 按钮语义

| 玩家按钮/开关 | 当前导出内容 | 何时使用 |
|---|---|---|
| 「更新战情」 | 所有当前已实现内容，包含地图、己方城市/单位、总督、商路和已遇见城邦信息 | 首次使用、没有最新战情、战情较旧、用户不确定是否已更新、信息缺失或需要完整刷新 |
| 「每回合自动更新」 | 每个本地玩家回合开始后刷新完整战情和当前可见地图 | 用户希望自动获得完整战情；默认关闭 |

## 给玩家的话术

无 snapshot 或首次使用：

```text
我还没读取到最新战情。请在 Civ6 点击左上副官入口，打开「战情简报」，点击「更新战情」。看到“简报已汇总，可继续由AI副官分析。”并确认最近更新回合后，回到这里继续分析。
```

地图/战争/定居信息不足：

```text
判断前需要前线可见地块和单位位置。请在 Civ6 左上副官入口打开「战情简报」，点击「更新战情」。看到“简报已汇总，可继续由AI副官分析。”后回到这里继续。
```

专题信息不足：

```text
当前快照缺少城市生产信息，不能可靠给出逐城生产建议。请打开「战情简报」并点击「更新战情」，看到简报已汇总后再继续。
```

多个模块缺失或状态混乱：

```text
当前战情上下文不完整。请打开「战情简报」并点击「更新战情」，等待完整情报刷新后再继续。若「每回合自动更新」刚完成且模块新鲜度满足要求，也可重新运行标准入口读取该结果。
```

## 平台回传

- 单机或同机分析：玩家完成点击后，终端按当前意图运行标准入口，例如 `npm run copilot -- --intent turn-priority --clean`。
- Windows 游戏机 + Mac Agent：Windows 侧完成点击后运行标准入口，生成并同步 handoff；Mac 侧读取 handoff。
- 如果用户说游戏界面由自己操作，AI 只给出战情简报按钮动作，并在终端侧运行标准入口或诊断命令。

## 排障优先级

- 面板打不开或左上没有副官入口：运行 `doctor`，检查 Mod 是否启用、是否进入真实对局、LaunchBar 按钮是否 attach。
- 面板显示成功但标准入口没有读取到新战情：运行 `doctor` 检查 Mod 日志、缓存状态和输出目录。
- `doctor` 缺少 `reason="exported"`：让玩家重新点击「更新战情」，并确认面板出现成功状态和最近汇总更新。
- manifest checksum/exportId 不一致：重新点击「更新战情」，并重新运行标准入口。
- API 低置信度：让玩家重进真实对局后点击「更新战情」；若仍低置信度，只能按低置信度来源分析。
