# 游戏内战情简报设计

战情简报是玩家在 Civ6 中汇总本地可见情报的入口。它应像游戏内战情面板，而不是开发者控制台：按钮清楚、状态简洁、技术细节交给日志和桌面工具。

## 1. 入口

- 入口挂在 Civ6 原生左上 LaunchBar 的 `ButtonStack`。
- 按钮使用 Civ6 可加载的原生图标/贴图作为主视觉信号。
- 加入按钮后 resize LaunchBar，避免静态坐标和原生 UI 重叠。
- 面板打开后贴近左上 LaunchBar 入口，避免悬浮在地图中央。
- 不使用强弹窗，不打断回合操作。

加载状态：

- XML context 先显示 `XML 已加载；等待 Lua 初始化。`。
- Lua 初始化成功后隐藏该诊断，并把面板切到 ready。
- 桌面工具结果由 doctor、manifest、preflight 和 handoff 显示，主面板只显示玩家可理解状态。

## 2. 布局

```text
战情简报

等待本回合情报汇总。
最近汇总：无

[更新战情]
[每回合自动更新：关] [关闭]
```

面板尺寸约 398×228；状态与最近采集占两行，主按钮独占一行，自动开关和关闭按钮并排。玩家只有一个手动完整刷新按钮；自动开关默认关闭，开启后与手动按钮采集范围相同。面板不显示模块名或分帧、编码等实现术语。

## 3. 稳定按钮与模块

| UI 名称 | 内部导出类型 | 模块范围 |
|---|---|---|
| 更新战情 | `full` | 当前所有已实现模块，包含可见地图 |
| 每回合自动更新 | `full` + `auto-turn` | 默认关闭；每个本地玩家回合采集所有已实现模块与预算限制的可见地图 |

意图与模块名（如 `cities`、`units`、`governors`、`trade`、`cityStates`）是桌面分析能力，不对应游戏内的专题按钮。Skill 和 preflight 需要情报时，统一指导玩家点击「更新战情」。

## 4. 汇总类型

手动「更新战情」会刷新本地玩家可见的完整已实现模块和地图。模块包括 selection、己方城市/单位、总督、商路、已遇见城邦及现有科技、市政、政体、资源和公开外交数据。地图仍只包含已揭示/当前可见地块，不是当前屏幕画面，也不是全图真相。

`moduleStatus` 保存每个已尝试模块的采集回合、时间和导出来源；桌面端根据内部意图按模块检查覆盖，模块缺失时仍统一指导玩家点击「更新战情」。模块整包替换；跨回合移除旧 payload，保留过期采集记录。未请求模块的 schema 占位不能用于分析。

「每回合自动更新」开启后刷新所有已实现模块和预算限制的可见地图。内部轻量 `syncTurn` 路径保留作诊断用途，不作为玩家自动更新流程。开关默认关闭并保留本地运行状态。

## 5. 自动汇总

「每回合自动更新」默认关闭。开启后，Mod 在本地玩家回合开始后排队执行完整更新，使用 `exportType=full`、`triggerKind=auto-turn`，并按 `localPlayerId + gameTurn` 去重。汇总任务分帧执行，避免在回合切换事件中长时间阻塞游戏 UI 或声音。

分帧范围包括：

- 可见地图扫描。
- `Lua.log` 分块输出。
- base64 只按当前输出 chunk 现算，不在写入前整包转换。

约束：

- 自动与手动复用相同的已实现采集路径；内部 `syncTurn` 仅用于诊断。
- 不调用 `Request*`、`Set*` 或 gameplay 修改 API。
- 不改变 snapshot schema 主体。
- 面板的状态行显示触发、排队与进度；详细诊断记录在 `CIV6_AI_COPILOT_DIAGNOSTIC`。

## 6. Skill 协作

Skill 判断信息不足时使用当前对话语言给出固定结构：先说明缺少什么，再给战情简报动作。当前简体中文界面的示例句式：

```text
请打开战情简报，点击「更新战情」。
```

```text
请打开战情简报，点击「更新战情」。
```

面板只需要让玩家确认“我已经按要求汇总了情报”。桥接、文件指纹、manifest、schema 和 fairness 由桌面工具负责。

## 7. UI 文案边界

主面板可见文案使用简体中文。`bridge`、`preflight`、`exportId`、`sha256`、chunk、manifest 等技术词只出现在日志、manifest、doctor、preflight、handoff 和开发文档中。

按钮 tooltip 只说明「更新战情」会手动刷新完整情报，不在游戏内重复多人公平声明。多人边界放在 README、玩家指南、skill 回复和桌面诊断中。
