# Civ6 AI Copilot v0.3.3

本版把日常分析交给 Agent 自己组装。Skill 列出能读取的战情项目；工具读取最后一次成功的「更新战情」，并按点名的模块返回。数据协议仍是 `0.3`，游戏规则和 Mod 行为与 `0.3.1` 相同。

## 更新内容

- 不传 `--module` 时返回这次导出的全部已采集模块。传入 `--module` 时只返回点名的项目。
- `--query` 只记录用户原话，不再用正则决定模块或是否允许分析。
- `--adjacent-units` 按 odd-r 给出己方单位相邻六格。`--render-map` 写出同一份导出的玩家可见六边形 SVG。
- `governors`、`trade`、`cityStates` 如果本次不可用，写入 `gaps`，结果仍是 `ready`。
- 回档后的新汇总会整份覆盖 `latest.json`，即使回合数更小。桌面侧不再拒绝更早回合，也不再把上一份模块并进这次导出。
- 导出时间不再作为拒绝条件。`needs-game-refresh` 只表示游戏里还没有写完的导出；日志或 Tuner 失败返回 `runtime-error`。

## 升级说明

- `compatVersion` 仍为 `0.3`，`schemaVersion` 和 `protocolVersion` 仍为 `0.3.0`。`0.3.1` 快照可以继续分析。
- 请更新 Agent Skill 和本地工具。Steam Workshop 的 `0.3.1` Mod 可以继续留在游戏里。
- 旧版 `0.1.x` 快照仍不能与 0.3 协议混用。
- Mod 仍是被动 UI/Utility Mod，`AffectsSavedGames=0`。

## 验证状态

- 本版用于实机试用。Windows Civ6、Mac Agent 和双人多人公平测试由发布后的实际使用继续确认。
- 离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用。如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
