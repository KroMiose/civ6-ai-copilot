# Civ6 AI Copilot v0.3.2

本版发布 Agent context Runtime。日常对局分析改为一次调用，由 Runtime 完成取数、校验、意图推断和上下文投影。数据协议仍是 `0.3`，游戏规则和 Mod 行为与 `0.3.1` 相同。

## 更新内容

- Agent Skill 的日常入口改为 `node scripts/context.mjs --query "<用户原话>"`。安装器写入本机 `runtime.json`，不依赖当前工作目录。
- `status=ready` 时一次返回身份、校验、分析摘要和上下文。正常分析不再拼接 `codex-prompt.md`、handoff 和多份 `latest.json`。
- 自然语言由 Runtime 推断分析焦点。本回合综合问题会要求可见地图。
- 同一已校验导出不会重复写盘。bridge 与 tuner 都按当前 manifest 的 `exportId` 跳过重写。
- 旧的 `npm run copilot -- --clean` 会在刷新之前清掉旧 handoff，避免刷新失败后仍留下一份看起来可分析的旧结果。

## 升级说明

- `compatVersion` 仍为 `0.3`，`schemaVersion` 和 `protocolVersion` 仍为 `0.3.0`。`0.3.1` 快照可以继续分析。
- 请更新 Agent Skill 和本地工具。Steam Workshop 的 `0.3.1` Mod 可以继续留在游戏里；Mod 与工具 patch 不一致时会提示，但不阻断分析。
- 旧版 `0.1.x` 快照仍不能与 0.3 协议混用。
- Mod 仍是被动 UI/Utility Mod，`AffectsSavedGames=0`。

## 验证状态

- 本版用于实机试用。Windows Civ6、Mac Agent 和双人多人公平测试由发布后的实际使用继续确认。
- 离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用。如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
