# Civ6 AI Copilot v0.3.5

本版把日常分析程序放进技能目录。更新时只替换 `skill/civ6-ai-copilot/`。数据协议仍是 `0.3`，游戏内 Mod 行为与 `0.3.1` 相同。

## 更新内容

- `scripts/context.mjs` 直接运行同目录的 `context-runtime.mjs`。
- 不再要求另装一份版本号相同的本地工具才能分析。
- 不要用旧工具目录里的安装校验器去核对新技能。版本以技能目录里的 `SKILL.md` 为准。

## 升级说明

- 从最新 GitHub Release 取出 `skill/civ6-ai-copilot`，整份覆盖现有技能目录。
- `compatVersion` 仍为 `0.3`。Steam Workshop 的 `0.3.1` Mod 可以继续留在游戏里。
- 覆盖后开启一个新对话。

## 验证状态

- 本版用于实机试用。Windows Civ6、Mac Agent 和双人多人公平测试由发布后的实际使用继续确认。
- 离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用。如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
