# Civ6 AI Copilot v0.3.4

本版把日常分析改成决策简报。不带参数的 `context` 不再返回整份原始战情。数据协议仍是 `0.3`，游戏规则和 Mod 行为与 `0.3.1` 相同。

## 更新内容

- 默认调用只返回城市、单位、研究、政策、经济和外交的短行，以及明确的缺口。
- 铺城、移动和战线用 `--map`。区域图默认半径 8，局部图默认 5，单次最大 20。
- `--city` 和 `--unit` 按名称或 id 展开一个对象。
- `--raw` 只把原始导出写到文件并返回路径。
- 未采集、不可用和地图截断保持未知：不能写成 0、空或安全。`upgradeCost` 为 0 不是免费升级。

## 升级说明

- `compatVersion` 仍为 `0.3`。`0.3.1` 快照可以继续分析。
- 请更新 Agent Skill 和本地工具。Steam Workshop 的 `0.3.1` Mod 可以继续留在游戏里。
- 旧版 `0.1.x` 快照仍不能与 0.3 协议混用。
- Mod 仍是被动 UI/Utility Mod，`AffectsSavedGames=0`。

## 验证状态

- 本版用于实机试用。Windows Civ6、Mac Agent 和双人多人公平测试由发布后的实际使用继续确认。
- 离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用。如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
