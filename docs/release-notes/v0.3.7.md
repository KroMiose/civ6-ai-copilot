# Civ6 AI Copilot v0.3.7

本版补上征召归属、可读的多人局面，以及世界图索引。数据协议仍是 `0.3`。Steam Workshop 不在本版更新。

## 更新内容

- 看得见的单位如果归属和原主不同，导出 `originalOwnerPlayerId`、`isLevied` 和 `levyTurnsRemaining`。
- 已遇见城邦导出 `suzerainPlayerId`。未遇见城邦仍然不导出。
- `session` 尽量使用 `GAMESPEED_*`、`MAPSIZE_*` 名称，并包含 `humanPlayerCount`。旧快照仍是哈希或 `UNKNOWN` 时，简报把它标成缺口。
- `--map world` 用数字标出城心和战略/奢侈资源，`places.marker` 对得上名称。SVG 使用资源全名。
- `visibleMap.worldIndex` 记录当前看得见的城心和战略/奢侈资源。详细地块仍有 1024 格上限。战争迷雾中的地块不读取。

## 升级说明

- 请安装这次发布里的 Mod，并整份替换 `skill/civ6-ai-copilot`。
- 进入游戏后点击一次「更新战情」，新字段才会出现在简报里。
- `compatVersion` 仍为 `0.3`。`0.3.1` 快照仍可分析，但没有征召、人类席位和世界索引。
- 不要用更早版本的工具目录去校验这一版技能。

## 验证状态

- 本版用于实机试用。Windows Civ6、Mac Agent 和双人多人公平测试由发布后的实际使用继续确认。
- 离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用。如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
