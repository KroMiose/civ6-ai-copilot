# Civ6 AI Copilot v0.3.1

本版将游戏内的手动刷新统一为「更新战情」，并扩充可供副官分析的本地玩家情报。它作为预发布版本提供，真实游戏与双人多人局测试将在发布后继续进行。

## 更新内容

- 「更新战情」一次采集当前已实现的全部模块；可选的「每回合自动更新」在每个己方回合执行同样的完整刷新，默认关闭。
- 新增己方城市生产、粮食与基础设施，单位状态，当前选择，总督、商路、已遇见城邦使者等决策数据；改进摘要的行动优先级。
- 面板统一更新状态、采集回合与进度的展示，减少空白并简化操作。
- 可见地图继续使用 1024 地块预算，并优先采样当前视野和己方单位、城市附近；迷雾中的地块不读取当前动态状态。
- 更新 bridge、tuner-bridge、快照校验与 Agent Skill，使它们按同一份 0.3 数据契约处理情报，并加强多人可见性检查。

## 升级说明

- 本版 `compatVersion` 为 `0.3`，`schemaVersion` 和 `protocolVersion` 为 `0.3.0`。旧版 `0.1.x` 的 Mod、Skill 和本地工具不能与本版混用；请一并更新，并在游戏内重新点击「更新战情」生成新快照。
- Steam Workshop 只更新 Mod。使用本地 AI 副官的玩家还需从本次 GitHub Release 更新 Agent Skill 和工具包。
- Mod 仍是被动 UI/Utility Mod，`AffectsSavedGames=0`，不修改玩法、存档或网络同步状态。

## 验证状态

- 已通过：构建、类型检查、199 项自动化测试、Mod/Skill 包校验、隐私检查、RC 自动 gate 和 fake `Lua.log` 离线闭环。
- 待补：Windows Civ6 实机加载与导出、两名真人玩家同局的多人公平交叉检查、Mac Agent handoff 实机测试。离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用；如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
