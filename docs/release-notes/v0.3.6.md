# Civ6 AI Copilot v0.3.6

本版修复 v0.3.5 技能目录内的分析程序无法启动的问题。数据协议仍是 `0.3`，游戏内 Mod 行为与 `0.3.1` 相同。

## 更新内容

- 打包后的运行时不再有重复的 shebang，也能在 ESM 里加载命令行依赖。
- 版本信息随技能目录分发，不依赖当前工作目录或另一份工具。
- 安装校验会真正运行一次 `context`。没有快照时可以返回「需要汇总」，但不能因语法或模块错误崩溃。
- 单位简报保留已受伤害 `damage`。`combatStrength` 是满编基础战斗力。
- 不在已遇见主要文明列表中的归属标为 `not-major`，不再一律写成「未知文明」。
- 重名单位会列出 id、坐标和归属。`upgradeCost` 为 0 的含义写在结果里。

## 升级说明

- 从最新 GitHub Release 取出 `skill/civ6-ai-copilot`，整份覆盖现有技能目录。
- 不要用 v0.3.5 或更早的工具目录去校验这一版。
- `compatVersion` 仍为 `0.3`。Steam Workshop 的 `0.3.1` Mod 可以继续留在游戏里。
- 覆盖后开启一个新对话。

## 验证状态

- 本版用于实机试用。Windows Civ6、Mac Agent 和双人多人公平测试由发布后的实际使用继续确认。
- 离线检查不能代替这些验证。

建议先在测试局或已征得同局玩家同意的多人局使用。如发现问题，请附游戏版本、Mod 版本和可复现步骤，不要公开原始快照或日志。
